# إعداد الدخول إلى لوحة معرض دبي

لوحة الإدارة: https://dubai-store-iq.netlify.app/admin/

تستخدم وظيفة Netlify أسماء المتغيرات التالية في Production:
- ADMIN_USERNAME: اسم المستخدم
- ADMIN_PASSWORD: كلمة مرور قوية لا تقل عن 12 حرفاً، وتكون Secret
- ADMIN_SESSION_SECRET: قيمة عشوائية سرية لا تقل عن 32 حرفاً، وتكون Secret

يجب أن تشمل صلاحيات المتغيرات نطاق Functions. بعد تغيير أي متغير، يلزم نشر جديد (Deploy) حتى يستعمله كود Functions.

هذا الملف تعليمات تشغيلية فقط؛ لا تُكتب كلمات المرور أو رموز الجلسة هنا أو في مستودع GitHub.
